# Agents of DATA: Online Code Breaking Challenge

This project is a **web-based educational escape-room-like activity** designed for **schoolchildren aged 9–12**.
It has been created for the client **Data Education in Schools** as part of a group software development project.

The activity is set in the *Agents of DATA* universe and aims to teach **data literacy and basic code-breaking skills** through interactive, puzzle-based challenges.

---

## Project Overview

Learners take on the role of **junior data agents** tasked with solving a series of code breaking challenges.  
Each challenge focuses on skills such as:

- Spotting patterns in data  
- Interpreting graphs and charts  
- Basic encryption and code-breaking  
- Making decisions based on imperfect or incomplete data  

The experience is designed to last **30–60 minutes** and follows an **escape room–style structure**, where learners progress by solving problems rather than being penalised for incorrect answers.

---

## Educational Design Principles

- **Fail-forward gameplay**: learners always make progress, even if answers are not perfect  
- **Multiple valid outcomes**: prevents answer-sharing and supports mixed-ability classrooms  
- **Inclusive and accessible**: clear visuals, minimal text, tablet-friendly interactions  
- **Engaging narrative**: urgency and story elements to maintain motivation  

---

## Technical Overview

- Frontend web application built using **HTML, CSS, and JavaScript**
- Designed to be **embedded within a WordPress site**
- Optimised for **laptops and tablets**, particularly iPads
- No server-side dependencies required
